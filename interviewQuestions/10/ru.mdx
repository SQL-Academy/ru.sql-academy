---

## DELETE:

- Удаляет выбранные записи из таблицы.
- Можно использовать условие `WHERE` для удаления конкретных записей.
- Операция записывается в журнал транзакций построчно.
- Срабатывают триггеры на `DELETE`.
- Медленнее по сравнению с `TRUNCATE`.

Пример:

```sql
DELETE FROM employees WHERE salary < 30000;
```

## TRUNCATE:

- Удаляет все записи из таблицы.
- Нельзя использовать `WHERE`.
- Операция быстрее, так как не логируется построчно.
- Сбрасывает счётчик автоинкремента: в MySQL — всегда, в PostgreSQL — с `RESTART IDENTITY`.
- Триггеры на `DELETE` не срабатывают (в PostgreSQL для `TRUNCATE` можно создать отдельный триггер).
- Возможность отката зависит от СУБД: в PostgreSQL `TRUNCATE` можно отменить через `ROLLBACK`, а в MySQL нельзя — команда неявно фиксирует транзакцию.

Пример:

```sql
TRUNCATE TABLE employees;
```
